Job Capture privacy

This extension reads the current page only when you select Capture this page. It extracts job details from visible posting text and structured JobPosting data. It does not crawl other pages or collect your browsing history, cookies, passwords, or resume.

Your draft stays on your device

The extension keeps one editable draft in Chrome’s local extension storage. It is not synced to other devices. Drafts expire after 24 hours and are removed the next time the extension opens. Use Clear draft to remove it immediately. Uninstalling removes extension storage. Exported JSON files remain wherever you save them.

You choose when to send

After you check the consent box and select Review in SagittaIQ, the reviewed fields and posting URL open in a SagittaIQ tab using a URL fragment. The extension makes no background network requests and uses no analytics, advertising, remote code, or AI service. That tab’s browser history may temporarily contain the capture until the updated SagittaIQ site imports and clears it.

SagittaIQ holds the imported draft in that tab’s session storage through sign-in, for up to 24 hours. Saving it to your account requires verified sign-in and a separate save action. Resume analysis is a separate action in SagittaIQ; data sent for that analysis is governed by the site’s policy.

Use and sharing

Captured data is used only for the job capture, review, export, and SagittaIQ handoff features. It is not sold, used for advertising, or shared with data brokers. The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including Limited Use requirements.

Read the SagittaIQ data and privacy notice for website storage and analysis practices. For support or deletion questions, use the developer contact listed on the Chrome Web Store listing.
